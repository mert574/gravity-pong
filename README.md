# Gravity Pong

A browser paddle game built with JavaScript and Canvas. Keep a gravity-driven
ball in play and compete against a computer-controlled opponent.

## Run locally

```sh
npm install
npm start
```

Open the local URL printed by the server. Press a key to start each round and
use Left/Right to move your paddle.
